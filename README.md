# Microscopic Parasite Classifier & Diagnostic Workstation

A lightweight, high-accuracy computer vision pipeline designed to classify microscopic slide images across internal, external, and environmental modules while using dedicated negative control classes (debris, air bubbles, plant fibers) to prevent false positives.

## Tech Stack
* **Deep Learning:** PyTorch, MobileNetV3-Large, Albumentations
* **Inference Optimization:** ONNX Runtime
* **Backend:** FastAPI
* **Frontend:** Tailwind CSS, Vanilla JavaScript
